# Vision and scope
Status: APPROVED except items marked TODO.

**Project:** L'ultimo treno per Natale — La Linea 24. A private 24-day digital Advent-calendar escape room for ONE experienced adult player. Italian. Target: ~15 minutes per puzzle, usually difficulty 4/5, occasional 5/5. Each day delivers meaningful story evidence, not only a numeric code. Atmosphere combines eerie mystery and nostalgic warm Christmas; 2D illustrated vintage railway 1976.

**Delivery goal:** fully prepared 24-day experience by December 1, 2026. No partial release is the intended final outcome. Implement platform skeleton now, content later; never misrepresent placeholders as complete. Primary device iPad, landscape preferred; must also work portrait/mobile. Very lightweight, static website, few images and touch controls, NO exploratory scenes or hidden hotspot hunting. Day-specific static background can change by chapter/day. Single recipient; no accounts, backend or database. Cloudflare Pages free static hosting.

**Player flow:** open calendar → select unlocked day → read story and examine static documents → interact with one puzzle → optionally reveal ONE subtle hint → submit unlimited attempts → see narrative resolution and earn inventory objects → diary records completed story. Previous unlocked days remain accessible, including unsolved days. Player may return to solve missing days. No item granted by date alone.

**Out of scope:** walking around train/city, draggable 2D worlds, multiplayer, payments, analytics, push notifications, admin CMS, sound, AI features, complex transitions, server-side protection. The image/style reference has NOT yet been provided; design must remain easy to reskin.

**Non-negotiables:** documentation-first; usable prototype; minimal dependencies; transparent content completeness; no fabricated final puzzles.
